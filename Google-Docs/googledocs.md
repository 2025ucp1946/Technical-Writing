# Google Docs

## What is Google Docs?

Google Docs is an online word processor. It allows users to create, edit, format, and share documents through a web browser.

## Main features

- Create and edit documents online.
- Automatically save changes to Google Drive.
- Share documents with other people.
- Allow multiple people to edit a document.
- Add comments and suggestions.
- View version history and restore earlier versions.

## Basic steps

1. Open [Google Docs](https://docs.google.com/).
2. Sign in with a Google account.
3. Select a blank document or a template.
4. Enter and format the content.
5. Rename the document.
6. Share it using the Share option.

## Formatting tools

- Use headings to organize the document.
- Use bold, italic, and underline for text formatting.
- Use numbered and bulleted lists.
- Insert tables and images when required.
- Use page setup to change margins and page orientation.

## Collaboration

1. Select **Share**.
2. Enter the email address of the person.
3. Choose a permission:
   - Viewer: can view the document.
   - Commenter: can view and add comments.
   - Editor: can make changes.
4. Send the invitation or copy the sharing link.

## Version history

Use **File → Version history → See version history** to view earlier versions. You can check changes and restore a previous version if needed.

## What I learned

I learned how to create and format documents, share them with others, collaborate in real time, add comments, and use version history.


## Practical example

Suppose I need to prepare a one-page note about Technical Writing.

1. Create a blank document.
2. Type the title \`Technical Writing\`.
3. Apply the **Title** style.
4. Add a heading named **What I learned**.
5. Add a short paragraph and a bulleted list.
6. Rename the document to \`Technical Writing Notes\`.

Example of the finished document:

\`\`\`text
             Technical Writing

What I learned

Technical Writing helps us present information
clearly and in an organized way.

Topics covered:
• LaTeX
• Beamer
• Doxygen
• Google Docs
• Git and GitHub
\`\`\`

This is an example of the content and layout. The actual page formatting depends on the font, alignment, and styles selected in Google Docs.

## Example of sharing output

If I share the document with a classmate as a **Viewer**, that person can open and read it but cannot edit it. If I choose **Editor**, that person can make changes.

## Example of version history

1. Type \`First draft\` and wait for it to save.
2. Change it to \`Updated draft\`.
3. Open **File → Version history → See version history**.

Expected result: Google Docs shows earlier saved versions with their dates and editors. You can open an older version or restore it.
